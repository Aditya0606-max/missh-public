# MISSH × VEVFM — pre-registered early-warning study (sepsis, MIMIC-IV)

Code, pre-registration rules and protocol for a pre-registered study of whether
a geometric reading of ICU vital signs warns of circulatory deterioration in sepsis
earlier than NEWS. Registration 1 (hourly MIMIC-IV) was signed and time-stamped
before a single test run; the result was null at hourly resolution.

No patient data is included. Running the code requires credentialed access to
MIMIC-IV on PhysioNet (https://physionet.org/content/mimiciv/).
