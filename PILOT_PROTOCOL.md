
## Test 4b (added before running; descriptive only)
Excursion reading on the same 15-min path. Excursion: Dw >= 1 starts it; peak = max Dw;
ends when Dw < 0.5 or data end. Per excursion: peak Dw; cosine at peak (Dw/D);
blocks to peak; return completeness = (peak Dw - end Dw)/peak Dw; return direction =
cosine(end - peak, -(peak - start)); HR held = HR z at end minus HR z at start;
assisted = any treatment start from 30 min before start to end. Memory: excursions
listed in order per patient; completeness and return blocks compared across order.
Stable patients read by the same rule.
